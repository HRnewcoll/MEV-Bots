## ⚠️ Requirements for Running MEV Bots

1. **Capital** — Most profitable bots need 0.25–5 ETH minimum
2. **Technical Knowledge** — Solidity, Web3, deep DeFi understanding
3. **Infrastructure** — Low-latency servers co-located near Ethereum nodes
4. **Risk Management** — MEV is highly competitive; losses are possible

### Recommended Starting Path

1. **[BowTiedDevil/degenbot](https://github.com/BowTiedDevil/degenbot)** — learn the patterns, well-documented Python
2. **[degatchi/memware](https://github.com/degatchi/memware)** — understand mempool operations
3. **This repo's simulator** (`python run.py`) — practice with no risk before going live
