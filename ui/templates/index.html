🚀 Quick Start (3 steps)
  1. 1
    Install dependencies — run once from the repository root: 
    pip install -r requirements.txt
    or on Linux / macOS: bash scripts/setup.sh --quick
  2. 2
    Launch the dashboard — from the repository root:

📖 Strategy Guide
Arbitrage
Compares token prices across multiple DEXs on the same chain. Buys on the cheapest DEX, sells on the most expensive. Profit = price difference minus gas cost.
Risk: low. Capital needed: yes (simulated here).
Sandwich
Detects large pending swaps in the mempool. Places a buy order just before them and a sell order just after, profiting from the price impact.
Risk: medium. Requires fast execution & Flashbots.
Liquidation
Monitors undercollateralized lending positions on Aave / Compound. When a position falls below the health threshold, liquidates it to earn the bonus.
Risk: medium. Requires capital in the debt token.
❓ FAQ
Do I need a private key to use the simulator?

No. The simulator only makes read-only RPC calls to fetch prices — it never sends transactions. You can test any strategy without any wallet or funds.

What RPC URL should I use?

The simulator comes pre-configured with free public RPCs for each chain. For better reliability use a dedicated endpoint from Alchemy, Infura, or QuickNode. Free tiers are sufficient for simulation.

What does "paper trading" mean?

Paper trading means running the bot logic against real live market data, but simulating the trades instead of executing them on-chain. Your virtual balance goes up or down based on what the real trades would have returned, letting you evaluate a strategy's performance risk-free.

How do I use the real (live) bots?

The live Python bots are in python/. Each has a .env file where you set your RPC URL and private key. Run bash scripts/setup.sh to install their dependencies, then navigate into the bot directory and run python bot.py. ⚠️ Only use real bots after thorough simulation testing — they spend real gas.

Trades are not showing up — what's wrong?

The simulation calls public RPCs to read live prices. If those RPCs are unreachable (e.g. in a restricted network), prices won't be fetched and no trades will fire. Try entering your own RPC URL in the Simulation tab config panel.

Can I access the dashboard from another device?

Yes. Launch with python run.py --host 0.0.0.0 and navigate to http://<your-ip>:5000 on the other device. Make sure your firewall allows the port.
